# MyWalletFlow — versões publicadas

Este repositório guarda **só as versões publicadas** do MyWalletFlow (app desktop de finanças pessoais para Windows):
o pacote portátil (`MyWalletFlow-vX.Y.Z-windows.zip`), o arquivo de verificação (`.sha256`) e as notas de cada versão.

- O app consulta a última versão daqui para se atualizar sozinho (Configurações › Sobre).
- O código-fonte não fica aqui.
- Seus dados financeiros nunca saem do seu computador: a consulta só pergunta qual é a versão mais nova.

Instalação manual: baixe o zip da versão em **Releases**, extraia e dê dois cliques em `MyWalletFlow.exe`.
